Bank Logos Directory
--------------------
Place your bank logo image files here:
- boc.png         -> Bank of Ceylon (BOC)
- commercial.png  -> Commercial Bank
- hnb.png         -> Hatton National Bank (HNB)

Recommended format: Transparent PNG or SVG (Square or Landscape, e.g., 200x200 or 400x200).
If a file is missing, the UI gracefully displays a styled monogram fallback badge with the bank's initials.
